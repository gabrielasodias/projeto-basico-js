# Verificador de Idade

Este é um projeto simples desenvolvido com HTML, CSS e JavaScript, que solicita o nome e a idade do usuário e exibe uma mensagem personalizada com base na idade informada.

## 🔍 Funcionalidades

- Entrada de nome e idade do usuário.
- Validação dos campos para garantir que ambos sejam preenchidos.
- Exibição de mensagens personalizadas com base na idade:
  - Menores de 18 anos: "Você é menor de idade."
  - 18 anos ou mais: "Você é maior de idade."
- Botão para limpar os campos e mensagens exibidas.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram adquiridos conhecimentos em:

- Manipulação do DOM para acessar e modificar elementos HTML.
- Uso de eventos para capturar ações do usuário, como cliques em botões.
- Validação de formulários para garantir a entrada correta de dados.
- Estruturas condicionais em JavaScript para exibir mensagens com base em condições específicas.
